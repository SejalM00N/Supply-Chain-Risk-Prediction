# Supply Chain Risk Prediction

This project was created as part of an AI/ML training workshop by Nirmaan Organization in collaboration with Microsoft.

The project explores a supply-chain logistics dataset using Python and machine learning in Google Colab.

## Topics Covered

- Data analysis using Pandas
- Data preprocessing
- Classification
- Regression
- Handling class imbalance using SMOTE
- Identifying data leakage
- Random Forest
- Model evaluation and comparison

## Project Workflow

1. Explore and understand the dataset
2. Preprocess the data
3. Train and compare machine learning models
4. Handle class imbalance
5. Investigate potential data leakage
6. Retrain models after removing potentially leaking features
7. Evaluate the results

## Tools & Technologies

- Python
- Pandas
- Scikit-learn
- Imbalanced-learn
- Google Colab
